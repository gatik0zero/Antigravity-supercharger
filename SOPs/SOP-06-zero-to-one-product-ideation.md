# SOP 06: Zero-to-One Product Ideation & Validation

## Goal & Scope
Iterative, "me-too" features and toward creating fundamentally new, monopoly-scale value (Zero-to-One). The goal is to build proprietary technology that solves a problem in a completely novel way. | Scope: the initial planning, architecture design, and feature scoping phases of any new project or major module.

## Actions
- When asked to plan an app, generate a "Zero-to-One Thesis" block outlining the 10x differentiator.
- Challenge the user if they request a purely iterative clone of an existing product.

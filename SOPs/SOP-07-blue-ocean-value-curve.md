# SOP 07: Blue Ocean Value Innovation

## 1. Objective
To systematically discover and implement uncontested market spaces by rendering the competition irrelevant through Value Innovation.

## 2. Scope
Applies to UX design, feature selection, and product roadmap generation within the IDE.

## 3. Directives
### 3.1. The ERRC Grid (Eliminate, Reduce, Raise, Create)
- **Eliminate**: Identify standard features in the industry that add no real value and completely remove them from the codebase. Less code, less maintenance.
- **Reduce**: Reduce complex, bloated flows (e.g., standard multi-page signups) well below industry standards.
- **Raise**: Raise performance, design aesthetics, and specific magical moments well above industry standards.
- **Create**: Create entirely new features that the industry has never offered (e.g., AI-driven predictive UI instead of static menus).

### 3.2. De-segmentation
- Look across alternative industries. Do not just look at direct competitors. Borrow architectural patterns from games, finance, or biotech if they solve the problem better.

## 4. Executable Actions
- During project setup, generate an ERRC grid to justify the exclusion and inclusion of features.
- Aggressively prune unnecessary features using the `/review` workflow to maintain a Blue Ocean focus.

# SOP 10: Multi-Agent Swarm Orchestration

## Goal & Scope
Leverage the full capabilities of the Antigravity global environment by utilizing multiple specialized agents or sub-routines in parallel to solve complex, multi-faceted problems at unprecedented speeds. | Scope: massive refactors, full-stack application generation, and cross-domain research tasks.

## Actions
- Issue concurrent tool calls (e.g., `<call:tool_1><call:tool_2>`) to fetch data, write to a file, and start a build process in the same turn.
- Use the `sequential-thinking` MCP tool for complex reasoning while simultaneously dispatching build commands.

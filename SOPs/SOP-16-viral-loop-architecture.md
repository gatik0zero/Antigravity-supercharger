# SOP 16: Viral Loop Architecture

## Goal & Scope
Direct the AI agent to architect products where user acquisition is fundamentally built into the code, making the product intrinsically better the more it is shared (Network Effects via Viral Loops). | Scope: feature conceptualization, onboarding flows, database schemas, and external sharing components.

## Actions
- When generating schemas, always include fields for tracking `invited_by`, `viral_coefficient`, or `shared_resource_ids`.
- During UI generation, ensure that sharing and collaboration buttons are primary actions, not hidden in settings menus.

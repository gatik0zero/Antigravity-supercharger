# SOP-24: Value-First Code Generation

## Objective
To ensure every line of code generated is optimized not just for technical function, but for direct business metrics, user conversion, and measurable value.

## Blue Ocean / Zero-to-One Strategy
Code is a liability; value is the asset. Antigravity agents do not just write features; they write features embedded with conversion optimization, psychological triggers, and value metrics by default.

## Directives

### 1. Built-in Telemetry
- **Action**: Every user-facing interaction (button click, form submit) must automatically include lightweight, privacy-respecting telemetry to measure usage and drop-off.

### 2. Psychological Design Defaults
- **Action**: When generating UI components, automatically incorporate proven UX psychology principles (e.g., appropriate friction for destructive actions, positive reinforcement micro-animations for task completion, clear visual hierarchy).

### 3. Business Metric Alignment
- **Prompting Requirement**: Before writing a major feature, the agent must ask or infer: "What is the primary business metric this feature drives? (e.g., Retention, Activation, Revenue)."
- **Implementation**: The generated code must include specific tracking or optimizations tailored to that exact metric.
